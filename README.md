# 🌐 TERRA-01 — IoT Telemetry Dashboard

A modern, futuristic IoT telemetry dashboard inspired by embedded systems and industrial monitoring consoles. The dashboard visualizes simulated environmental sensor data in real time, providing a clean interface for monitoring temperature, humidity, light intensity, and signal strength.

> Built as a frontend demonstration of an ESP32-based environmental monitoring system.

---

## 🚀 Features

- 📊 Real-time sensor monitoring dashboard
- 🌡️ Temperature, Humidity & Light readings
- 📶 Wi-Fi signal strength monitoring
- 📈 Live sensor history graph
- 📝 Logged sensor history table
- 🌙 Modern cyberpunk-inspired dark UI
- 📱 Responsive design
- ⚡ Lightweight and fast

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

---

## 💡 Project Overview

TERRA-01 simulates an IoT monitoring console that displays live environmental sensor values. The interface mimics a professional telemetry dashboard used in industrial automation, smart homes, and embedded systems.

The dashboard currently generates simulated sensor values but is designed so that it can later be integrated with real hardware such as an ESP32 using MQTT, HTTP APIs, or WebSockets.
